# 内置示例皮肤：小灰猫（demo-cat）

这是**内置皮肤**，随应用分发。装好后打开「设置 → 桌宠」就能在列表里看到它，
不需要导入。点「试穿」预览、点「应用」即可换装。

## 里面有什么

```
demo-cat/
├── pet.json     # 皮肤描述（帧动画配置）
└── atlas.png    # 图集：768×576，8 列 × 6 行，每格 96×96，共 48 帧
```

### 基础动作（帧 0–31）

| 帧号 | 动作 | fps | 说明 |
| --- | --- | --- | --- |
| 0–5 | `idle` 待机 | 6 | 呼吸起伏；第 5 帧眨眼 |
| 6–11 | `walk` 走路 | 10 | 四足交替抬起 + 身体上下颠 |
| 12–15 | `sleep` 睡觉 | 3 | 蜷成一团、闭眼、尾巴绕到身前 |
| 16–19 | `interact` 被按 | 12 | 惊一下 → 睁大眼 → 回常态（末帧是常态） |
| 20–25 | `celebrate` 庆祝 | 10 | 弹跳两次、张嘴 |
| 26–28 | `snap` 贴边 | 5 | 歪头眯眼 |
| 29–31 | `drag` 被拎起 | 7 | 腿垂下、耳朵后贴、尾巴翘起 |

### 方向变体（帧 32–47，阶段 8.7）

拖拽分上下左右、走路分左右、贴边按边。**方向不是新状态**，
只是同一状态的不同画面；缺哪个方向就回落到基础动作。

| 帧号 | 变体 | 说明 |
| --- | --- | --- |
| 32–33 | `drag-up` | 向上被拎：腿收得更紧、张嘴 |
| 34–35 | `drag-down` | 向下垂：腿伸直 |
| 36–37 | `drag-left` | 整体左倾，瞳孔看向左 |
| 38–39 | `drag-right` | 整体右倾，瞳孔看向右 |
| 40–41 | `walk-left` | 头朝左、腿序镜像 |
| 42–43 | `walk-right` | 头朝右、腿序镜像 |
| 44 | `snap-up` | 贴屏幕上边：翻转 120° + 缩到 0.78 |
| 45 | `snap-down` | 贴屏幕下边：正常站姿 |
| 46 | `snap-left` | 贴屏幕左边：侧倾 52° + 缩到 0.72 |
| 47 | `snap-right` | 贴屏幕右边：侧倾 52° + 缩到 0.72 |

> **为什么贴边要缩放**：猫本身偏宽（x 约 26–90），绕中心一转就会顶出 96 宽的帧。
> 纯倾斜到 36° 就已经贴到 x=0 了，所以示例用「倾斜 + 缩放」。
> 阴影固定画在未变换的画布上，倾角也不能太大 —— 150°/180° 会把阴影转到 y=95 贴死底边。
> 这些边界值都是实测出来的，改角度后请重跑 `node tools/gen-demo-cat.js` 看是否有贴边告警。

> 状态名、`loop` 与 `duration` 由状态机决定，`pet.json` 里没有也不该写 ——
> 详见 `docs/PET_ANIMATION_SPEC.md` 第 6 节。

## 想改成自己的猫？

图集是**程序生成**的，不用手绘：

```bash
node tools/gen-demo-cat.js
```

- 画图工具：`tools/atlas-kit.js`（纯 Node + zlib 手写 PNG，不依赖 canvas / electron）
- 画法：用有符号距离函数描述椭圆 / 多边形 / 胶囊，再 3×3 超采样抗锯齿
- 改颜色：`tools/atlas-kit.js` 顶部的 `C`（调色板）
- 改动作：`tools/gen-demo-cat.js` 里每个状态的帧参数（`bodyY` / `earTilt` /
  `legPhase` / `tailPts` / `tilt` 整体倾斜 / `poseScale` 姿态缩放 等）
- 加方向动画：在 `FRAMES` 里追加帧、并在 `clips` 里用 `状态名-方向` 声明
  （如 `'drag-left': { frames: [36, 37], fps: 7 }`）
- 改了帧数记得同步改 `clips` 里的 `frames`，否则帧号会越界（越界不报错，只是画出空白）
- 图集行数不够时改 `tools/atlas-kit.js` 的 `ROWS`（当前 6，容 48 帧）

## 想把它做成可分享的皮肤包？

把这两个文件压成一个 zip，别人在「设置 → 桌宠 → 导入 zip」即可安装。
也可以直接复制到 `<userData>/pets/demo-cat/` 下。

`pet.json` 里的 `id` 是安装目录名，改 `id` 就等于换一个皮肤（可与内置版共存）。
