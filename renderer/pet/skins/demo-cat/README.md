# 内置示例皮肤：小灰猫（demo-cat）

这是**内置皮肤**，随应用分发。装好后打开「设置 → 桌宠」就能在列表里看到它，
不需要导入。点「试穿」预览、点「应用」即可换装。

## 里面有什么

```
demo-cat/
├── pet.json     # 皮肤描述（帧动画配置）
└── atlas.png    # 图集：768×384，8 列 × 4 行，每格 96×96，共 32 帧
```

| 帧号 | 动作 | fps | 说明 |
| --- | --- | --- | --- |
| 0–5 | `idle` 待机 | 6 | 呼吸起伏；第 5 帧眨眼 |
| 6–11 | `walk` 走路 | 10 | 四足交替抬起 + 身体上下颠 |
| 12–15 | `sleep` 睡觉 | 3 | 蜷成一团、闭眼、尾巴绕到身前 |
| 16–19 | `interact` 被按 | 12 | 惊一下 → 睁大眼 → 回常态（末帧是常态） |
| 20–25 | `celebrate` 庆祝 | 10 | 弹跳两次、张嘴 |
| 26–28 | `snap` 贴边 | 5 | 歪头眯眼 |
| 29–31 | `drag` 被拎起 | 7 | 腿垂下、耳朵后贴、尾巴翘起 |

> 状态名、`loop` 与 `duration` 由状态机决定，`pet.json` 里没有也不该写 ——
> 详见 `docs/PET_ANIMATION_SPEC.md` 第 6 节。

## 想改成自己的猫？

图集是**程序生成**的，不用手绘：

```bash
node tools/gen-demo-cat.js
```

- 画图工具：`tools/atlas-kit.js`（纯 Node + zlib 手写 PNG，不依赖 canvas / electron）
- 画法：用有符号距离函数描述椭圆 / 多边形 / 胶囊，再 3×3 超采样抗锯齿
- 改颜色：`tools/atlas-kit.js` 顶部的 `C`（调色板）
- 改动作：`tools/gen-demo-cat.js` 里每个状态的帧参数（`bodyY` / `earTilt` /
  `legPhase` / `tailPts` 等）
- 改了帧数记得同步改 `clips` 里的 `frames`，否则帧号会越界（越界不报错，只是画出空白）

## 想把它做成可分享的皮肤包？

把这两个文件压成一个 zip，别人在「设置 → 桌宠 → 导入 zip」即可安装。
也可以直接复制到 `<userData>/pets/demo-cat/` 下。

`pet.json` 里的 `id` 是安装目录名，改 `id` 就等于换一个皮肤（可与内置版共存）。
