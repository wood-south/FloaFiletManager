# 桌宠帧动画（atlas）制作标准 v1

> 本文是**桌面浮窗管理器桌宠皮肤**的帧动画制作规范。按本文做完的皮肤包可以被
> 「设置 → 桌宠 → 导入文件夹 / 导入 zip」直接导入并应用。
>
> 本文的每条约束都对应实现代码，不是设想：
>
> | 内容 | 实现位置 |
> | --- | --- |
> | `pet.json` 字段与校验 | `renderer/pet/skin.js` |
> | 帧推进与图集寻址 | `renderer/pet/frames.js` |
> | 画布绘制与回落 | `renderer/pet/skin-render.js` |
> | 配色换色 | `renderer/pet/colors.js` |

> | 打包格式规范（总体） | `docs/PET_SPEC.md` |

## 1. 帧动画是怎么跑起来的

一句话：**状态机决定「什么时候播什么」，皮肤只决定「这个动作长什么样」。**

```
用户操作 / 自主行为驱动
        │
        ▼
  behavior.js 状态机          7 个状态、优先级、一次性回落
        │  当前状态名（如 walk）
        ▼
  frames.js 帧播放器          按 fps 把「已播时长」换算成帧序号
        │  当前图集帧号（如 5）
        ▼
  skin-render.js              按 frameWidth/frameHeight 把该帧从图集裁出来
        │
        ▼
  <canvas> 绘制到 90×90 视觉框
```

关键点：

- **你不控制「什么时候播」**。状态机在桌宠空闲时会自己切到 `walk`、长时间无操作会切到
  `sleep`、拖放上传成功会切到 `celebrate`（见 `renderer/pet/driver.js`）。
  你的皮肤只需要为这些状态各准备一段帧序列。
- **`fps` 是「帧推进速度」而不是「动画时长」**。想把一段动作放慢，就降低 `fps`
  或增加帧数（同一帧重复出现也有效，例如 `[0,1,2,1]` 是 4 帧的循环）。
- **图集是一张静态图片**，帧按网格排列，运行时按坐标裁切。
  不支持 GIF / APNG / 动图 WebP —— 你交的必须是静态图集。

## 2. 快速开始（最小可用皮肤）

```
my-cat/
├── pet.json
└── atlas.png
```

`pet.json`：

```jsonc
{
  "format": "pet",
  "version": 1,
  "id": "my-cat",
  "name": "我的猫",
  "render": {
    "kind": "sprite",
    "atlas": { "file": "atlas.png", "frameWidth": 64, "frameHeight": 64 }
  },
  "clips": {
    "idle": { "frames": [0, 1, 2, 1], "fps": 6 },
    "walk": { "frames": [3, 4, 5, 4], "fps": 10 },
    "interact": { "frames": [6, 7], "fps": 12 }
  }
}
```

`atlas.png` 至少要有 8 帧（即 8 个 64×64 格子）。**没有在 `clips` 里声明的状态会自动
用第 0 帧当静帧**，所以只做 `idle` 也能跑，只是其它动作会僵住。

导入后：设置 → 桌宠 → 皮肤列表出现「我的猫」→ 点「试穿」预览 → 点「应用」。
应用后**立即换装，无需重启**。

## 3. 文件与目录布局

```
<皮肤目录>/
├── pet.json          # 必需，必须叫这个名字
├── atlas.png         # 图集（文件名任意，用 render.atlas.file 指过去）
├── meow.ogg          # 可选音效（文件名任意，用 sounds 指过去）
└── ...               # 其它资源随意放，支持子目录
```

### 3.1 硬性限制

| 项 | 限制 | 说明 |
| --- | --- | --- |
| `pet.json` | 必须在**根目录** | 若整个包被套在一层文件夹里（`my-cat/pet.json`），导入时会**自动下钻一层** |
| 单文件大小 | ≤ **4 MB** | 超了整包拒绝 |
| 整包总大小 | ≤ **32 MB** | 按解压后计算 |
| 文件数 | ≤ **256** | — |
| zip 包本身 | ≤ **64 MB** | 仅 zip 导入时有此限制 |
| 资源路径 | 必须**相对路径** | 禁止 `..`、绝对路径、`C:\`、`file://`、任何协议前缀 |
| 扩展名白名单 | 见下 | 不在白名单的资源会被拒绝 |

**允许的扩展名**

```
图片：.png .jpg .jpeg .webp .gif .bmp .ico .svg
音频：.ogg .mp3 .wav .m4a
字体：.ttf .otf .woff .woff2
其它：.json .css
```

> **包内出现 `.js` `.exe` `.dll` `.bat` `.cmd` `.ps1` `.vbs` `.scr` 会整包拒绝**，
> 即使这些文件没有被 `pet.json` 引用。这是安全策略，不是疏忽。

### 3.2 打包成 zip

你可以直接把上表目录压成 zip 分发。两种布局都支持：

```
✔ pet.json 在 zip 根              ✔ 只有一层顶层目录（自动下钻）
  ├── pet.json                       └── my-cat/
  └── atlas.png                          ├── pet.json
                                         └── atlas.png
```

含 `..` 或绝对路径的条目会被拒绝（防路径穿越）。

## 4. `pet.json` 字段规范

### 4.1 顶层

```jsonc
{
  "format": "pet",        // 必需，固定 "pet"
  "version": 1,           // 必需，本规范版本
  "id": "my-cat",         // 必需，见下
  "name": "我的猫",        // 必需，非空，列表里显示的名字
  "author": "你的名字",     // 可选
  "render": { },          // 必需，见 §5
  "clips": { },           // 可选，见 §6（帧动画的核心）
  "sounds": { }           // 可选，见 §7
}
```

**`id` 命名规则**：`^[a-z0-9][a-z0-9-]{0,47}$`

- 只允许小写字母、数字、连字符；必须以字母或数字开头；最长 48 字符
- ✔ `my-cat` `cat2` `a`
- ✘ `My-Cat`（大写）`-cat`（连字符开头）`my cat`（空格）`我的猫`（中文）
- **id 同时是安装目录名**。导入时若 id 相同会**覆盖安装**。

**`format` / `version` / `id` / `name` 任一不合法 → 整包拒绝**（`ok: false`），
不会降级使用。其余字段的问题只记 warning 并忽略该字段。

### 4.2 未列出的字段

一律忽略。**向前兼容**：以后新增的字段不会让旧版本报错，你可以放心加自己的注释字段。

## 5. `render`：怎么画

### 5.1 帧动画（`kind: "sprite"`）

```jsonc
"render": {
  "kind": "sprite",
  "size": { "width": 90, "height": 90 },      // 可选，设计标注
  "atlas": {
    "file": "atlas.png",                      // 必需
    "frameWidth": 64,                         // 必需，正整数
    "frameHeight": 64                         // 必需，正整数
  },
  "svg": { "file": "fallback.svg" }            // 可选，图集不可用时的兜底
}
```

- `atlas.file` 缺失/路径不安全，或 `frameWidth`/`frameHeight` 不是正数 →
  **回落到 `svg` 分支**；连 `svg` 也没有就用**内置 SVG 猫**。
- `size` 只是设计标注，**不决定实际显示尺寸**。实际视觉框固定为 90×90
  （由 `renderer/styles/float.css` 的 `.pet-avatar` 决定），画布内容会被等比铺进去。
  **建议 `frameWidth` = `frameHeight`**，否则会被拉伸变形。

### 5.2 SVG 皮肤（`kind: "svg"`）

```jsonc
"render": {
  "kind": "svg",
  "svg": {
    "file": "cat.svg",
    "colorMap": { "--cat-fur": "#f5a623", "--cat-ear": "#f8c774" }
  }
}
```

`colorMap` 只支持**预定义的 CSS 变量名**（见 §8），写别的变量名会被忽略。

### 5.3 回落优先级（一张图看清）

```
kind = sprite
  ├── atlas 合法 ──────────────► 用帧动画
  └── atlas 非法
        ├── 有合法 svg.file ──► 用该 SVG
        └── 否则 ─────────────► 内置 SVG 猫
kind = svg
  ├── svg.file 合法 ──────────► 用该 SVG
  └── 否则 ───────────────────► 内置 SVG 猫
运行期图集图片解码失败 ────────► 保留内置 SVG 猫（绝不白屏）
```

## 6. `clips`：帧序列（核心）

```jsonc
"clips": {
  "idle":     { "frames": [0, 1, 2, 1], "fps": 6 },
  "walk":     { "frames": [3, 4, 5, 4], "fps": 10 },
  "interact": { "frames": [6, 7],       "fps": 12 }
}
```

| 字段 | 必需 | 规则 |
| --- | --- | --- |
| 键名 | — | 必须是 §6.1 里的状态名，**未知状态名会被忽略** |
| `frames` | 是 | 非负整数数组，**不能为空**。元素是**图集帧序号**（从 0 开始） |
| `fps` | 否 | 正整数，默认 **8**。非正数/非数字 → 用默认值并记 warning |

### 6.1 七个状态与它们的语义

| 状态名 | 何时播放 | 循环 | 优先级 | 时长 |
| --- | --- | --- | --- | --- |
| `idle` | 默认/空闲 | ✔ 循环 | 0 | — |
| `sleep` | 用户空闲 60 秒后（与待机随机循环） | ✔ 循环 | 20 | — |
| `walk` | 空闲期间随机漫游（**会真的移动窗口**） | ✔ 循环 | 40 | 随机 1.2~3.2 秒 |
| `celebrate` | 上传/删除成功 | ✘ 一次性 | 60 | 1.2 秒 |
| `interact` | 按下桌宠 | ✘ 一次性 | 70 | 0.6 秒 |
| `snap` | 吸附到屏幕边缘/Dock | ✔ 循环 | 90 | — |
| `drag` | 正在拖动 | ✔ 循环 | 100 | — |

**你必须知道的四条规则**（都由状态机强制，皮肤无法改变）：

1. **`loop` 和 `duration` 由状态表决定，`clips` 里写了也会被忽略**。
   所以 `celebrate` 无论你怎么写都是「播 1.2 秒然后回 idle」。
   这是刻意的：否则皮肤能把一次性状态改成循环，桌宠会永远卡在庆祝动作上。
2. **优先级不可覆盖**。`drag`(100) 能打断一切，`idle`(0) 打断不了任何状态。
3. **一次性状态播完停在最后一帧**，不会跳回第 0 帧（避免视觉跳变）。
   所以 `interact` 最后一张图应是「回到常态」的姿势。
4. **没声明的状态用第 0 帧静帧**。要桌宠「每个动作都不一样」，就得逐个声明。

### 6.2 方向变体：拖拽分上下左右、走路分左右、贴边按边

有些动作需要**按方向**给不同画面。做法是在基础状态名后加方向后缀：

```
drag-up   drag-down   drag-left   drag-right   drag
walk-left  walk-right  walk
snap-up   snap-down   snap-left   snap-right   snap
```

- **方向名**：`up` `down` `left` `right`；`top`/`bottom` 与 `up`/`down` 等价
  （贴边语境说"上边"、拖拽语境说"向上"，指向同一组变体）
- **七个状态没有变**。`drag-left` 不是第八个状态，只是 `drag` 的一个方向变体，
  优先级/循环/时长仍按 `drag` 算
- **回退链**：方向变体 → 不带方向的同名 clip → 第 0 帧静帧

**回退是重点**：你只画一组 `drag` 也能用（任意方向都播它），
只画 `drag-left` 也能用（缺的方向回落到基础 `drag`）。
所以**旧皮肤包不用改**，加方向只是让效果更精细。

引擎何时用哪个方向：

| 状态 | 方向来源 |
| --- | --- |
| `drag` | 拖动位移的**主轴**（竖直位移大就算 up/down，否则 left/right） |
| `walk` | 当前行走方向（走动中撞到边界会反向，动画随之翻转） |
| `snap` | 吸附到哪条边（贴左边 → `snap-left`；贴 Dock 左边同理） |

> 走路的移动逻辑：自由状态**左右**漫游；吸附到屏幕边缘/Dock 后
> **沿那条边**滑动 —— 贴左右边时改为竖直走，贴上下边时水平走。
> 走到屏幕边界会**自动反向**，不需要（也无法）在动画包里配置。

### 6.3 帧序号怎么对应到图集

帧序号 = 从左上角起、**按行优先**的格子编号：

```
frameWidth = 64, frameHeight = 64

 列0    列1    列2    列3
┌─────┬─────┬─────┬─────┐
│  0  │  1  │  2  │  3  │  行0
├─────┼─────┼─────┼─────┤
│  4  │  5  │  6  │  7  │  行1
├─────┼─────┼─────┼─────┤
│  8  │  9  │ 10  │ 11  │  行2
└─────┴─────┴─────┴─────┘
```

- 每行列数 = `floor(图集宽度 ÷ frameWidth)`，**由图片实际宽度自动算出**，
  你不需要在 `pet.json` 里声明列数。
- 上例：图集 256×192，`floor(256/64) = 4` 列。
- 第 N 帧的裁切坐标：`x = (N mod 列数) × frameWidth`，`y = floor(N ÷ 列数) × frameHeight`。

> ⚠️ **帧序号越界不会报错**（只是画出空白/错位）。请自己核对
> `最大帧序号 < 列数 × 行数`。

### 6.4 帧率与时长参考

| 动作 | 建议帧数 | 建议 fps | 效果 |
| --- | --- | --- | --- |
| `idle` 呼吸 | 4~8 | 4~8 | 缓慢起伏，太快会显得焦躁 |
| `walk` 走路 | 4~8 | 8~12 | 与「走一小段就停」的节奏匹配 |
| `sleep` 睡觉 | 2~4 | 2~4 | 慢速呼吸/冒泡 |
| `interact` 反馈 | 2~4 | 10~15 | 0.6 秒内演完，建议最后一帧是常态姿势 |
| `celebrate` 庆祝 | 4~8 | 8~12 | 1.2 秒内演完，同上 |
| `snap` 贴边 | 2~4 | 4~8 | 轻微摇摆 |
| `drag` 被抓 | 2~4 | 6~10 | 挣扎/晃腿 |

## 8. 换色（`colorMap`）与内置变量清单

内置 SVG 猫的颜色通过 CSS 变量生成，你可以只改配色而不画图：

```jsonc
"render": {
  "kind": "svg",
  "svg": { "file": "cat.svg", "colorMap": { "--cat-fur": "#3a3a3a" } }
}
```

| 变量名 | 内置默认值 | 用途 |
| --- | --- | --- |
| `--cat-fur` | `#f5a623` | 主体毛色（头/耳/爪） |
| `--cat-ear` | `#f8c774` | 耳内 |
| `--cat-stripe` | `#e8941a` | 头顶纹理 |
| `--cat-whisker` | `#d4903a` | 胡须 |
| `--cat-ink` | `#333` | 眼睛/嘴巴线条 |
| `--cat-nose` | `#e85d5d` | 鼻子 |
| `--cat-cheek` | `#ffb6b6` | 腮红 |

规则：

- 变量名必须匹配 `^--[a-zA-Z0-9-]+$`，且**必须在上面清单里**；
  清单外的一律忽略（皮肤不能往桌宠上塞任意 CSS 变量）。
- 颜色值是任意合法 CSS 颜色串（`#rgb` / `#rrggbb` / `rgba(...)` / `red` 等）。
- **换回内置皮肤时变量会被清除**，所以不必担心残留。

> 💡 用 `colorMap` 配合 `kind: "svg"` 可以做出「同一只猫不同配色」的皮肤，
> 资源体积几乎为零。

## 9. 校验规则与错误信息

导入时返回 `{ ok, errors, warnings, skin }`：

- **`errors` 非空 → `ok: false`，整包被拒绝**，桌面宠物不会改变。
- **`warnings` → 仅提示，皮肤仍可用**（通常是某字段被忽略或回落）。

### 9.1 会导致整包拒绝（errors）

| 情况 | 错误信息 |
| --- | --- |
| 不是 JSON 对象 | 皮肤文件不是一个 JSON 对象 |
| `format` ≠ `"pet"` | format 必须为 "pet" |
| `version` ≠ 1 | 版本不支持（更高版本会被明确拒绝，而不是误读） |
| `id` 不匹配命名规则 | id 非法（需匹配 `^[a-z0-9][a-z0-9-]{0,47}$`） |
| `name` 为空 | name 不能为空 |
| 缺 `render` | 缺少 render 对象 |
| 资源文件不存在 | 资源文件不存在: xxx |
| 资源路径试图越出目录 | 资源路径不安全（试图越出皮肤目录） |
| 资源扩展名不在白名单 | 不允许的资源类型: xxx |
| 单文件 / 整包 / 文件数超限 | 单文件超限 / 整包超限 / 文件数超限 |
| 包含可执行/脚本文件 | 皮肤包内不允许出现可执行/脚本文件: xxx |

### 9.2 只记 warning（字段被忽略或回落）

| 情况 | 结果 |
| --- | --- |
| `render.kind` 非法 | 回落 `svg` |
| `atlas` 缺字段或帧宽高非正 | 回落 `svg` 分支 |
| `frames` 非法/为空 | 忽略该 clip（该状态回到静帧） |
| `fps` 非正数/非数字 | 用默认 8 |
| `clips` 出现未知状态名 | 忽略该项 |
| `colorMap` 变量名非法或不在清单 | 忽略该项 |
| `size` 非正数 | 用内置 90×90 |

**形象化理解**：`errors` 是「这个包不能用」，`warnings` 是「这个包能用，但某些部分我没看懂」。

## 10. 制作流程与自查清单

### 10.1 推荐流程

1. **定动作清单**：先决定要做哪几个状态（至少 `idle`）。
   要做方向动画就再加变体（如 `drag-left`、`walk-right`、`snap-up`，见 §6.2）；
   **不做也能用** —— 缺方向时会自动回落到不带方向的那条。
2. **定帧尺寸**：`frameWidth`/`frameHeight` 取**所有动作中的最大包围盒**，并保持一致。
   建议 64×64 或 96×96；不要用奇数尺寸（缩放会糊）。
   注意：**整体倾斜的姿态会变宽**（猫绕中心转一下就可能顶出帧），
   要么把倾斜角控制在 ±10° 内，要么同时缩小姿态（示例皮肤用「倾斜 + 缩放」）。
3. **画帧、拼图集**：按 §6.3 行优先排列；**每格内容必须居中对齐同一基线**，
   否则动作会「跳」。
4. **写 `pet.json`**：`frames` 用图集格号。
5. **自查**（见 10.2）。
6. **试穿**：设置 → 桌宠 → 试穿预览，确认画面正确
   （预览会**逐个动作播放**，包括方向变体，可一次看全）。
7. **应用**：点「应用」，桌宠立即换装。

### 10.2 提交前自查清单

- [ ] `pet.json` 在包根目录，文件名完全一致（区分大小写）
- [ ] `format` = `"pet"`，`version` = `1`
- [ ] `id` 匹配 `^[a-z0-9][a-z0-9-]{0,47}$`（全小写、无空格中文）
- [ ] `name` 非空
- [ ] `render.kind` = `"sprite"`
- [ ] `atlas.file` 指向真实存在的图片，路径是相对路径
- [ ] `frameWidth` / `frameHeight` 是**正整数**，且与图集实际网格吻合
- [ ] 图集宽度能被 `frameWidth` 整除（否则最后一列会被切半）
- [ ] 所有 `frames` 里的数字都是**非负整数**，且**小于 图集总格数**
- [ ] `frames` 数组非空
- [ ] 每个做好的动作都在 `clips` 里声明了（否则该状态是静帧）
- [ ] 方向变体的**后缀拼写正确**（`-up`/`-down`/`-left`/`-right`）；
      拼错不会报错，只会静默回落到基础 clip
- [ ] 倾斜/缩放的姿态**没有像素贴到帧边**（贴边会被切掉一角）
- [ ] 没有 `.js`/`.exe` 等可执行文件混在包里
- [ ] 单文件 ≤ 4MB、总量 ≤ 32MB、文件数 ≤ 256
- [ ] 图片是**静态图**（不是 GIF/APNG/动图 WebP）

## 11. 已知限制（v1）

以下为当前实现的真实边界，不要按它们设计：

| 限制 | 说明 |
| --- | --- |
| **音效未播放** | `sounds` 只做校验与保存，尚未接入播放 |
| **不支持九宫格/偏移** | 帧只能是等大矩形网格，不支持 anchor/pivot 偏移 |
| **不支持逐帧时长** | 一个 clip 内所有帧共用一个 `fps` |
| **不支持非网格图集** | 必须是规则网格；不规则排布需自己补透明边距对齐 |
| **图集整张常驻内存** | 图集会被解码进内存，别做过大的图（建议 ≤ 2048×2048） |
| **帧序号越界静默** | 越界不报错，只是画出空白/错位，需自行核对 |
| **`size` 不影响显示** | 实际视觉框固定 90×90，`size` 仅作设计标注 |
| **不支持动图格式** | GIF/APNG/动图 WebP 不会被当作动画播放 |

## 12. 完整参考示例

一个可直接导入的最小包（8 帧图集，3 个动作）：

```
demo-cat/
├── pet.json
└── atlas.png        # 256×128，4 列 × 2 行，每格 64×64
```

```jsonc
{
  "format": "pet",
  "version": 1,
  "id": "demo-cat",
  "name": "演示猫",
  "author": "示例作者",
  "render": {
    "kind": "sprite",
    "size": { "width": 90, "height": 90 },
    "atlas": {
      "file": "atlas.png",
      "frameWidth": 64,
      "frameHeight": 64
    }
  },
  "clips": {
    // 待机：4 帧循环，来回呼吸（注意末帧回到 1 而不是 0，避免循环时突跳）
    "idle": { "frames": [0, 1, 2, 1], "fps": 6 },

    // 走路：用 3~5 帧循环
    "walk": { "frames": [3, 4, 5, 4], "fps": 10 },

    // 按下反馈：一次性 0.6 秒，末帧是常态姿势
    "interact": { "frames": [6, 7], "fps": 12 },

    // 睡觉：复用待机帧但放慢
    "sleep": { "frames": [0, 1], "fps": 2 },

    // 庆祝：复用 6/7 但放慢，1.2 秒内演完
    "celebrate": { "frames": [6, 7, 6, 7], "fps": 8 },

    // 贴边与拖动：轻微摇摆
    "snap": { "frames": [0, 1], "fps": 4 },
    "drag": { "frames": [3, 5], "fps": 8 }
  }
}
```

图集网格对照：

| | 列0 | 列1 | 列2 | 列3 |
| --- | --- | --- | --- | --- |
| **行0** | 0 idle-常态 | 1 idle-吸气 | 2 idle-最鼓 | 3 walk-抬左腿 |
| **行1** | 4 walk-换脚 | 5 walk-抬右腿 | 6 interact-受惊 | 7 interact-恢复 |
